# أحكام الأسرة للأقليات المسلمة في الغرب بين الفقه والقانون: الأرجنتين نموذجًا

مادة بحثية أولية لرسالة علمية، مبنية على إشكاليات واقعية تواجهها الأسرة المسلمة في الأرجنتين (الخطبة، الزواج، الطلاق، النسب، الحضانة، النفقة). الترتيب في كل إشكالية: الواقع، فالفقه، فالقانون، فالمقارنة ووجه الحل.

> **الحالة:** مادة أولية للدراسة، وليست نص الرسالة. وسوم المصادر: `[نص]` و`[نص بواسطة]` و`[منقول]` و`[تحليل]` و`[يحتاج تحققًا]`، ومعناها في `05_مجلد_البحث/00_مشترك/قالب_ملف_الإشكالية.md`.

## البنية
| المسار | المحتوى |
|---|---|
| `HANDOFF.md` | حالة العمل وما تبقى والقواعد، لمن يتابع العمل |
| `04_خطة_الإشكاليات/` | تقرير الإشكاليات والمخطط المقترح للرسالة |
| `05_مجلد_البحث/00_مشترك/` | النصوص القانونية الأرجنتينية مع الترجمة، وسجل قرارات المجامع، وسجل الأحكام القضائية، وقالب الإشكالية |
| `05_مجلد_البحث/الفصل_الثالث/` | الخطبة (6)، الزواج (9)، الطلاق (7) |
| `05_مجلد_البحث/الفصل_الرابع/` | النسب (5)، الحضانة (5)، النفقة (5) |
| `03_مصادر_قانونية_بعد_2015/` | تقرير المصادر وكشف الملفات والنصوص الرسمية والأحكام |
